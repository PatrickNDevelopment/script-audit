# AI assistance

ScriptAudit can, optionally, call an AI provider through its local backend (see docs/spec/02-ai-broker-and-api.md); that feature is off unless configured and opted into.

This repository was written with Anthropic's Claude (through Claude Code) as the implementing
engineer, under a human owner's specification and review. The specification, code and tests were
generated and then verified by running the commands recorded in `docs/test-report.md`. Treat that
report, not this note, as the evidence of what works.
